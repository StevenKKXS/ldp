# Direction B: Action-Sequence Predictive Encoder Pretraining

## 方向目标

把“图像/历史到动作序列翻译”弱化为 encoder pretraining，让 encoder 通过预测 past + future action sequence 学到 action-predictive belief representation。

## 核心假设

- 预测动作序列能迫使 encoder 表达与控制相关的状态和历史信息。
- 预训练后的 encoder 可能比直接让 diffusion loss 端到端反传更稳定。
- past + future prediction 可能比 future-only 更好地约束 history 表示，但也可能引入捷径，需要实验验证。

## 输入形式

- 优先使用多帧 observation history。
- 备选为单帧图像加历史 action。
- 训练目标为 past + future action sequence 或 future-only action sequence。

## Action Prediction Decoder 设计

待详细 plan 定稿。初始候选:

- 轻量 MLP / transformer decoder 从 encoder embedding 预测 action sequence。
- decoder 只用于预训练，接入 PTP 时丢弃或作为辅助头单独 ablate。
- decoder 容量不能过强，否则可能绕过 encoder 表征质量问题。

## Future-Only 与 Past+Future Prediction 对比

待详细 plan 定稿。第一阶段建议至少比较:

- future-only action prediction。
- past + future action prediction。

需要检查 past action 是否让任务过于容易，从而降低对未来控制状态的学习压力。

## Loss 设计

待详细 plan 定稿。初始候选:

- normalized action MSE / Huber。
- gripper 与 pose 分量可分权重。
- rotation representation 需要与当前 PTP / robomimic action 处理保持一致。

## 接入 PTP 的方式

待详细 plan 定稿。初始候选:

1. 用 Direction B 预训练 encoder。
2. 接入 PTP / diffusion policy condition。
3. 分别测试 frozen encoder 与 finetune encoder。
4. 与 PTP baseline 和 same architecture no-pretrain baseline 对比。

## Square / ToolHang 优先实验矩阵

第一阶段只做:

| Task | Baseline | Same Arch No-Pretrain | Ours Frozen | Ours Finetune |
|---|---|---|---|---|
| Square | Required | Required | Required | Required |
| ToolHang | Required | Required | Required | Required |

## Push-T / Transport 扩展条件

仅当第一阶段满足以下任一条件时扩展:

- ours > same architecture no-pretrain baseline。
- ours 在至少一个任务上明显提升 PTP baseline。

## Ablation 设置

待详细 plan 定稿。初始候选:

- future-only vs past+future。
- decoder capacity。
- action loss type。
- frozen vs finetune。
- single-frame vs multi-frame history。
