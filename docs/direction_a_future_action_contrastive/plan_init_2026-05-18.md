# Direction A: Future-Action / Behavior Contrastive History Encoder

## 方向目标

用未来专家动作相似性组织 history embedding，使 encoder 学到 action-aware / behavior-aware 的历史表征。

## 核心假设

- 如果两个 observation history 对应的未来专家动作序列相似，则它们应该在 encoder embedding 空间更近。
- 如果当前视觉状态看起来相似但未来动作不同，则它们应被作为 hard negative 拉开。
- 这种 behavior-aware encoder 可能比仅靠 diffusion loss 反传更稳定地学到对控制有用的历史表示。

## 输入形式

- 优先使用多帧 observation history。
- 如果多帧实现成本过高，可先使用单帧图像加历史 action。
- 未来动作序列作为相似性监督，不作为 encoder 推理时的输入。

## Contrastive Loss 设计

待详细 plan 定稿。初始候选:

- 基于 future action sequence distance 构造 soft positive weights。
- 使用 InfoNCE / supervised contrastive / soft nearest-neighbor loss 作为候选。
- action distance 需要先讨论 normalization、rotation representation 和 gripper/action scale。

## Hard Negative 设计

待详细 plan 定稿。初始候选:

- image/history embedding 或 observation 相似但 future action distance 大的样本。
- 同 task 内相近时间窗口但不同阶段的样本。
- 需要避免把 demonstration style difference 错当作 hard negative。

## 接入 PTP 的方式

4. 与 PTP baseline 和 same architecture no-pretrain baseline 对比。

- ours > same architecture no-pretrain baseline。
- ours 在至少一个任务上明显提升 PTP baseline。
